# ✦ Karutoki Blogs

> A little corner of thoughts, poetry, stories and words.

**Karutoki Blogs** is a personal writing platform built to bring poems, blogs and late-night thoughts together in one calm, minimal space.

It is designed as more than just a blog — it's a personal digital journal where thoughts can be written, published and explored.

---

## ✨ Features

- 🏠 Minimal personal homepage
- ✍️ Poems section
- 📖 Blogs section
- 🌙 Midnight Talks section
- 📚 Individual writing pages
- 🔍 Writing-focused navigation
- 🌓 Dark / Light mode
- 📱 Responsive design
- 🔐 Secure admin authentication
- 📝 Admin dashboard
- ☁️ Supabase-powered content management
- 🚀 Dynamic content fetched from the database

---
